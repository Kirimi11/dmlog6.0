# DmLog

カードゲームの対戦成績・デッキ相性・大会ポイントなどを記録する個人用Webアプリです。

- 大会ポイントの自動計算：参加人数と順位から「基礎ポイント × 参加人数ごとの倍率 ×（ジャッジボーナス1.2）」を小数点以下切り捨てで計算
- 対戦記録、カレンダー、デッキ相性分析、次回の使用候補、対策デッキ検索
- 相手デッキ図鑑・リンク集・外部データ（全タブ共通）、複数集計画面（タブ）
- データの書き出し・読み込み（暗号化対応）

データはこの端末のブラウザ内（localStorage）に保存されます。

```bash
npm install
npm run dev
```
